# Camryn Burger Photography • The Union Lab Web Application

Welcome to the **CB Photography Webapp** project repository! This repository contains both the **C# ASP.NET Core Solution** and the **Next.js React Web Application**.

---

## Quick Start Instructions

## How to run app: 

**1.** Download and open the project folder on to your Desktop

**2.** Double-click the file named CB Photography Webapp.slnx (or CB Photography Webapp.csproj) if this doesn't work right click and select 'open with visual studio'

**3.** Visual Studio will launch and load the project automatically.

**4.** click the green Start / Play button at the top of Visual Studio.

**Visual Studio will then build the web app and launch it in your browser**
